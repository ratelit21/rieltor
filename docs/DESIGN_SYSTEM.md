# Визуальная система: три цвета

Сохранены два согласованных цвета из утверждённых скриншотов. Третий, шампанский, используется **как акцент**, а не как ещё один цвет фона.

| Назначение | HEX | Использование |
|---|---|---|
| Графитово-зелёный | **#252B28** | Архитектурные фоны, навигация, hover кнопок на тёплом камне, тёмные секции |
| Тёплый камень | **#DCCFBF** | Шесть одинаковых карточек каталога, форма, блок описания квартиры, светлая секция принципов |
| Шампанский | **#D7BC97** | Кнопки, выбранные фильтры, крупные номера 01/02/03, стрелки, тонкие линии и смысловые выделения |

Цвета заданы в `app/editorial-theme.css`, который подключается **после** базовой сетки `app/globals.css`. Не добавлять самостоятельные бронзовые, зелёные и бежевые оттенки для украшения. Светлый текст на тёмном использует каменный тон; текст на камне — графитовый. Шампанский текст **не размещать на каменном фоне**, где контраст недостаточен.

## Поведение компонентов

- На тёмной поверхности главная кнопка: шампанский фон + графитовый текст; hover: прозрачная + видимая шампанская обводка и текст.
- На тёмной поверхности вторичная кнопка: прозрачная + шампанская обводка и текст; hover: шампанская заливка + графитовый текст.
- На светлой карточке CTA: шампанская заливка + графитовый текст; hover: графитовая заливка + шампанский текст.
- Выбранный фильтр: шампанский с графитовым текстом; при наведении инверсия. Невыбранный фильтр сохраняет тонкую обводку и контрастное наведение.
- Номера 01, 02, 03: одинаковые графитовые секции на каменном холсте, крупная шампанская типографика, без отдельного цвета у средней карточки.
- Иконки только из `lucide-react` SVG; без эмодзи/символов как подмены иконок.
- Все шесть объявлений без GSAP `clip-path` и без уменьшения изображения. Подбор, форма и прокрутка должны работать.
- Обычный текст >=15 px, нормальная толщина, без мелкого жирного капса.
- Тексты, hover и состояния должны сохранять контраст не менее 4.5:1 для обычного шрифта.

## Проверка перед объединением

В GitHub Actions `Visual Contract` запускаются production-сборка и браузерные тесты на 390/768/1440 px: шесть одинаковых планировок, отсутствие переполнения и JS ошибок, контраст кнопок и hover, размер и положение стрелок, мобильное меню, фильтры и скролл-сцена. Переходы оцениваются и по реальным скриншотам.

**Главное правило:** дальнейший арт-дирекшн не должен молча возвращаться к двухцветной схеме или вводить четвёртый декоративный цвет.
