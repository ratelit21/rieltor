# К. — визуальная система сайта (стабильная версия)

Референсы художественного подхода: [Aman Residences](https://www.aman.com/residences) — архитектурная сдержанность; [Fantastic Frank](https://www.fantasticfrank.com/) — редакционная подача объектов. Не копировать конкретные страницы.

## Строгая палитра

Источник: `app/editorial-theme.css` (поверх `globals.css`, который отвечает за сетки).

| Роль | Токен | Цвет | Где применять |
|---|---|---|---|
| Основной тёплый фон | `--canvas` | `#E4DDD2` | Главная вводная секция, «Три принципа», архив, область деталей |
| Фирменный лесной | `--forest` | `#31483F` | Контрастный CTA главной, фон страницы заявки, фильтры |
| Угольный | `--night` | `#252B28` | Hero, история, текстовые панели карточек |
| Шампанский | `--champagne` | `#D8BC8A` | Форма заявки, кнопки на тёмном, редкие акценты |
| Глубокий шампанский | `--champagne-soft` | `#B99A67` | Hover заполненных шампанских кнопок |
| Светлый текст (не заливка) | `--ivory` | `#EEE7DC` | Текст на лесном и угольном |
| Основной текст | `--ink` | `#252B28` | Текст на камне/шампанском |

**Запрещено:** новые произвольные оттенки коричневого и зелёного; белые и молочно-белые заливки кнопок и карточек; монохромные одноцветные блоки подряд без редакционного контраста.

## Интерактивные состояния

- На угольном фоне: **шампанская** кнопка с угольным текстом; при наведении — более глубокий шампанский. Никакой белой заливки, никакой тёмной кнопки на таком же тёмном фоне.
- На тёплом фоне: **лесная** кнопка со светлым текстом; при наведении — шампанская с лесным текстом.
- В зелёной секции: шампанская кнопка; hover — глубокий шампанский.
- На шампанской форме: лесная кнопка, hover — тёплый камень с зелёной обводкой и текстом.
- Фильтры: светлый контур по камню, активный лесной; неактивный hover шампанский; активный hover — немного светлее лесной.
- Проверять **два состояния каждой кнопки**, включая контраст текста не ниже WCAG AA (4.5:1), читаемую границу и видимый переход заливки. Тонко и без дёрганья.

## Геометрия и код

- Все шесть объявлений — одинаковые сетки 1:1 на десктопе, 1 колонка на телефоне, планировка занимает полный блок и не подрезается `clip-path`.
- GSAP **не может** менять размеры и маски каталога; допустим только спокойный hover самого изображения.
- Стрелки из `lucide-react` (SVG, никаких emoji или Unicode вместо иконок), `display: flex` / `align-items: center`.
- Текст интерфейса от 15 px, без жирного микрокапса.
- Скролл-эпизоды и reduced-motion не ломать.

## Обязательная проверка

`Visual Contract` GitHub Actions + реальный Chrome на 390/768/1440 px: все маршруты, **шесть полноразмерных изображений**, согласованные сетки, ховеры, цвета, форма, меню, SVG и быстрая прокрутка сцены. Полные скриншоты просматривать отдельно — автоматические тесты не устанавливают художественную красоту.

Никаких непроверенных редизайнов в `main`.
