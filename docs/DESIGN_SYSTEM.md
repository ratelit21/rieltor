# Визуальная система сайта

**Основа:** Aman Residences (https://www.aman.com/residences) + Fantastic Frank (https://www.fantasticfrank.com/). Берём сдержанность, спокойные натуральные материалы, иерархию фотографий и редакционную сетку. Не копировать чужие интерфейсы.

## Палитра (источник: `app/editorial-theme.css`)

| Роль | Токен | HEX | Использование |
|---|---|---|---|
| Льняной фон | `--canvas` | `#EAE5DC` | Основной холст всех внутренних страниц |
| Светлая бумага | `--surface` | `#F7F3ED` | Карточки каталога, форма, описание квартиры |
| Подложка плана | `--sand` | `#E9E3D8` | Изображения и планы |
| Угольный графит | `--night` | `#252B28` | Главная, финальный CTA и навигация |
| Редакционный графит | `--warm-graphite` | `#282B29` | Скролл-история с фотографией |
| Типографика | `--ink` | `#292E2B` | Текст на тёплом льне |
| Зелёный акцент | `--forest` | `#31483F` | Только кнопки на светлом, выбранные фильтры и редкие смысловые акценты |
| Шампанский | `--champagne` | `#D8BC8A` | Редкие акценты на тёмном; не ставить мелкий шампанский текст на светлом |

**Не добавлять** четвёртый тон зелёного, коричневую секцию или золотой градиент. Красивая фотография и типографика важнее цветной плашки.

## Компоненты и состояния

- Основная кнопка на светлом: глубокий лесной + светлый текст; hover: светлый фон + зелёная рамка и текст. Не допускать слияния с подложкой.
- Кнопка на тёмном: светлый фон + графитовый текст; hover: шампанский фон + графитовый текст.
- Вторичная на тёмном: прозрачная с видимой светлой рамкой; hover: светлая заливка + графитовый текст.
- Фильтр: тёмный текст и обводка на льне; выбранный — зелёная заливка + светлый текст; hover должен отличаться от обоих состояний.
- Обычный текст не меньше 15–16px, без жирного капса ради премиального эффекта.
- Вся навигация и стрелки — Lucide SVG; никаких emoji и Unicode-стрелок вместо иконок.
- Все 6 карточек каталога имеют одинаковую реальную ширину и **не применяют GSAP clip-path к изображению**. Единственное движение в каталоге — спокойный hover картинки без обрезки карточки.
- Архитектурный эпизод на десктопе допускает GSAP, планировка вписана в общий визуальный кадр без scale-pop; при быстром скролле состояние синхронизируется с текущим эпизодом.
- `prefers-reduced-motion`: контент видим без анимации.

## Обязательная проверка изменений

GitHub Actions **Visual Contract** (`.github/workflows/visual-contract.yml`), `scripts/verify-visual-contract.mjs`: Next.js production build, реальные Chrome-проверки 390 / 768 / 1440 px, все маршруты, фильтры, демо-форма, SVG, цвета, переходы, **все 6 полноразмерных карточек**, а также контраст hover/focus состояний. WCAG 2.2: обычный текст >= 4.5:1.

Дополнительно нужны реальные скриншоты и визуальная оценка — автоматический тест не может подтвердить художественное качество.
